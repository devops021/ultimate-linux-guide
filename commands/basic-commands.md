## Useful Vim Delete Command	Meaning
x	→ Delete character<br>
dw	→ Delete word<br>
dd	→ Delete line<br>
D	→ Delete to end<br>
d$	→ Delete to end of line<br>
:%d	→ Delete all<br>
di"	→ Delete inside quotes<br>
u	→ Undo<br>
ctrl+r → Redo<br>
